# Operação Escudo Digital

Escape Room educacional para a 1ª série do Ensino Médio.

## Publicação no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html` para a raiz.
3. Em Settings > Pages selecione Deploy from a branch, `main` e `/ (root)`.

## Regras
São cinco salas, cada uma com duas rodadas alternativas de cinco questões. Ao errar, o jogador recomeça a sala em outra rodada. A cada acerto aparece um dígito para anotar. Cinco acertos consecutivos permitem digitar o código da sala. O progresso de salas completas é salvo no armazenamento local do navegador. Não há conexão em tempo real entre alunos e professor.

Referências pedagógicas: Cartilha de Segurança para Internet do CERT.br, https://cartilha.cert.br/ .
